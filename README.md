One-line entry for the make.fun bounty "Make the AI Judge Laugh: Cat Reviews Its Human": `main.py` writes a single funny one-star review, written by a house cat about its human, to `/output/entry.txt`, gated to 1–200 UTF-8 characters and not only white space, then re-reads the file to confirm it byte for byte.

## Run it

```sh
mkdir -p /output
python3 main.py
cat /output/entry.txt
```
